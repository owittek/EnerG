# EnerG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**UI:** Control Center–style tiles, chosen via a throwaway prototype (see Task 8).

**Goal:** Build EnerG, a macOS menu bar app plus a root daemon. It enforces a native Charge Limit, runs Discharge and Auto-Discharge by cutting adapter power, drives the MagSafe LED, and offers Top Up and Pause.

**Architecture:** All policy lives in a deep `Engine` module in the local Swift package `EnerGKit`. The Engine is fed `Event`s and writes through a `Hardware` port. There are two adapters at that port: `MacHardware` (SMC + PowerUI + IOKit, in the package so the smoke tool can reuse it) and `FakeHardware` (tests).

The `energd` daemon is a thin composition root. It is registered via `SMAppService.daemon`, serves XPC with a same-team peer requirement, and forwards system events into the Engine. `EnerG.app` is a thin SwiftUI `MenuBarExtra` client.

**Tech Stack:**
- Swift 6 (language mode 6), SwiftUI, Swift Testing.
- XPC (`XPCListener`/`XPCSession` with `XPCPeerRequirement`), ServiceManagement, IOKit.
- C/ObjC shim for AppleSMC and PowerUI.
- XcodeGen 2.46, Xcode 27.1.

Spec: `docs/superpowers/specs/2026-10-20-energ-design.md`. Glossary: `CONTEXT.md`. Use glossary terms (Charge Limit, Discharge, Discharge Target, Auto-Discharge, Top Up, LED Mode, Pause, Weak Adapter) in code names and UI copy.

## Global Constraints

- Target: macOS 27.0, Apple Silicon only. No Intel and no legacy SMC keys (`CH0B`/`CH0C`/`CHTE`).
- Swift language mode 6 everywhere. Package `swift-tools-version: 6.0`.
- Bundle IDs: app `app.energ.EnerG`, daemon label and mach service `app.energ.energd`, launchd plist `app.energ.energd.plist`.
- Signing: Apple Development, team `PHC7F926XU`, automatic signing, hardened runtime on.
- Charge Limit values: exactly `[80, 85, 90, 95, 100]`. A limit of 100 disables the native limit.
- SMC values:
  - `CHIE`: `0x00` = adapter on, `0x08` = adapter off.
  - `ACLC`: `0x00` = system, `0x01` = off, `0x03` = green, `0x04` = orange, `0x06` = slow blink.
- Native limit via PowerUI `PowerUISmartChargeClient`: `setMCLLimit:error:`, `enableMCL:`, `disableMCL:`, `getMCLLimitWithError:`, `isMCLCurrentlyEnabled:`.
- No license file yet. Clean-room: do not copy AlDente code.
- `EnerG.xcodeproj/`, `build/`, `.build/` are gitignored (already in `.gitignore`).
- Never leave the machine with the adapter cut. Every manual script restores adapter on, LED system and the original limit on exit.

## Deviations from spec (agreed during planning)

- The package is named `EnerGKit` with two library products: `EnerGCore` (Engine, Policy, Hardware port, Protocol, SettingsStore) and `EnerGMac` (`MacHardware` + the `CPlatform` C/ObjC shim). The smoke tool is the executable `energ-smoke`. `MacHardware` lives in the package, not in `energd/`, so the smoke tool can use it.
- Spike 2 (adapter presence while `CHIE`=08) is dropped. Policy never needs it: a Discharge ends at its target either way. The UI shows "Cut by EnerG" during a Discharge.
- Spike 3 (5% band) is dropped (it was documentation-only).
- The Optimized Battery Charging warning is dropped. EnerG owns the native limit.
- The `.lidClosed` event becomes `.lid(closed: Bool)`. While asleep or with the lid closed, no Discharge starts.
- The tick runs every 30 s unconditionally (simpler than "only while active").

```swift
import ServiceManagement
import XPC
import EnerGCore

// Spike UI; replaced in Task 8.
@main
struct EnerGApp: App {
    @State private var log = "—"

    var body: some Scene {
        MenuBarExtra("EnerG", systemImage: "bolt.batteryblock") {
            Text(log)
            Button("Register helper") { log = Spike.register() }
            Button("Open Login Items") { SMAppService.openSystemSettingsLoginItems() }
            Button("Ping helper") { log = Spike.ping() }
            Button("Unregister helper") { log = Spike.unregister() }
            Button("Quit") { NSApplication.shared.terminate(nil) }
        }
    }
}

@MainActor
enum Spike {
    static let daemon = SMAppService.daemon(plistName: DaemonID.plistName)

    static func register() -> String {
        do { try daemon.register() } catch { return "register error: \(error)" }
        return "status: \(daemon.status.rawValue) (1 enabled, 2 needs approval)"
    }

    static func unregister() -> String {
        do { try daemon.unregister() } catch { return "unregister error: \(error)" }
        return "status: \(daemon.status.rawValue)"
    }

    static func ping() -> String {
        do {
            let session = try XPCSession(machService: DaemonID.machService, options: .privileged, requirement: .isFromSameTeam())
            defer { session.cancel(reason: "done") }
            let pong: Pong = try session.sendSync(Ping())
            return "pong uid=\(pong.uid)"
        } catch {
            return "ping error: \(error)"
        }
    }
}
```

```swift
import Foundation

/// User-chosen configuration; persisted by energd.
public struct Settings: Codable, Equatable, Sendable {
    /// Charge Limit values the native macOS limit accepts. 100 means "no limit".
    public static let allowedLimits = [80, 85, 90, 95, 100]

    public var chargeLimit: Int
    public var autoDischarge: Bool
    public var ledMode: LEDMode
    public var paused: Bool

    public init(chargeLimit: Int = 80, autoDischarge: Bool = true, ledMode: LEDMode = .auto, paused: Bool = false) {
        self.chargeLimit = chargeLimit
        self.autoDischarge = autoDischarge
        self.ledMode = ledMode
        self.paused = paused
    }
}

/// How EnerG drives the MagSafe LED.
public enum LEDMode: String, Codable, Sendable, CaseIterable {
    /// Orange while charging, green when holding, off during a Discharge.
    case auto
    /// Always off (while not paused and plugged in).
    case off
    /// Like auto, but slow blink during a Discharge.
    case blink
}

/// A concrete LED output. `system` hands the LED back to firmware.
public enum LEDState: String, Codable, Sendable {
    case system, off, green, orange, blinkSlow
}

/// One reading of battery and power state.
public struct BatterySnapshot: Codable, Equatable, Sendable {
    public var percent: Int
    public var isCharging: Bool
    /// Adapter power reaches the Mac. False while EnerG cuts the adapter for a Discharge.
    public var adapterConnected: Bool
    /// Rated adapter wattage, if known.
    public var adapterWatts: Int?
    /// Positive while charging, negative while the battery supplies power.
    public var batteryWatts: Double
    /// Total system draw, if known.
    public var systemWatts: Double?

    public init(percent: Int, isCharging: Bool, adapterConnected: Bool,
                adapterWatts: Int?, batteryWatts: Double, systemWatts: Double?) {
        self.percent = percent
        self.isCharging = isCharging
        self.adapterConnected = adapterConnected
        self.adapterWatts = adapterWatts
        self.batteryWatts = batteryWatts
        self.systemWatts = systemWatts
    }
}

/// A hardware-backed capability that can become unavailable when its write fails.
public enum Feature: String, Codable, Sendable, CaseIterable {
    case chargeLimit, discharge, led
}

public enum ChargeState: String, Codable, Sendable {
    case charging, atLimit, discharging, toppingUp, paused, onBattery, unknown
}

public enum Warning: Codable, Hashable, Sendable {
    case weakAdapter
    case unavailable(Feature)
    case batteryUnreadable
}
```

```swift
/// A message from EnerG.app to energd. Every request is answered with a `Status`.
public enum Request: Codable, Equatable, Sendable {
    case getStatus
    case setLimit(Int)
    case discharge(to: Int)
    case cancelDischarge
    case topUp
    /// Ends a Top Up early; the Charge Limit applies again.
    case cancelTopUp
    case setLEDMode(LEDMode)
    case setAutoDischarge(Bool)
    case setPaused(Bool)
    /// Hand everything back to macOS (same as Pause); sent before uninstalling the helper.
    case release
}

public struct Status: Codable, Equatable, Sendable {
    public var state: ChargeState
    public var settings: Settings
    /// nil when the battery could not be read.
    public var snapshot: BatterySnapshot?
    /// Set while a Discharge is running.
    public var dischargeTarget: Int?
    public var warnings: [Warning]

    public init(state: ChargeState, settings: Settings, snapshot: BatterySnapshot?,
                dischargeTarget: Int?, warnings: [Warning]) {
        self.state = state
        self.settings = settings
        self.snapshot = snapshot
        self.dischargeTarget = dischargeTarget
        self.warnings = warnings
    }
}
```

```swift
import Foundation

/// JSON persistence for `Settings`. A missing or unreadable file yields defaults.
public struct SettingsStore: Sendable {
    public let url: URL

    public init(url: URL) { self.url = url }

    public func load() -> Settings {
        guard let data = try? Data(contentsOf: url),
              let settings = try? JSONDecoder().decode(Settings.self, from: data) else { return Settings() }
        return settings
    }

    public func save(_ settings: Settings) throws {
        try FileManager.default.createDirectory(at: url.deletingLastPathComponent(), withIntermediateDirectories: true)
        try JSONEncoder().encode(settings).write(to: url, options: .atomic)
    }
}
```

```swift
/// Everything the Engine needs from the machine. Writes may throw; the Engine
/// then marks the matching `Feature` unavailable and stops writing it.
public protocol Hardware: AnyObject {
    func snapshot() throws -> BatterySnapshot
    /// Sets the native Charge Limit; nil disables it.
    func setChargeLimit(_ percent: Int?) throws
    /// false cuts adapter power so the Mac runs from the battery.
    func setAdapter(enabled: Bool) throws
    func setLED(_ state: LEDState) throws
    /// Holds an idle-sleep assertion while on.
    func setPreventSleep(_ on: Bool)
}

public enum HardwareError: Error, Equatable, Sendable {
    case notPrivileged
    case keyMissing(String)
    case frameworkUnavailable
    case io(Int32)
}
```

```swift
/// Runtime state the Engine keeps between events (not persisted).
struct Session: Equatable {
    /// Set while a Discharge runs.
    var dischargeTarget: Int?
    var toppingUp = false
    /// Blocks Auto-Discharge after the user cancels one; cleared on unplug or at/below the limit.
    var autoSuppressed = false
    var weakSamples = 0
    var unavailable: Set<Feature> = []
    var sleeping = false
    var lidClosed = false

    var canStartDischarge: Bool { !unavailable.contains(.discharge) && !sleeping && !lidClosed }
}

/// What the hardware should look like right now.
struct Actuation: Equatable {
    var chargeLimit: Int?
    var adapterEnabled: Bool
    var led: LEDState
    var preventSleep: Bool

    /// Stock macOS behaviour: used for Pause and release.
    static let released = Actuation(chargeLimit: nil, adapterEnabled: true, led: .system, preventSleep: false)
}

enum Policy {
    /// Advances the session for a fresh snapshot: ends Top Up and suppression on unplug,
    /// ends a finished Discharge, starts Auto-Discharge, and counts Weak Adapter samples.
    static func update(settings: Settings, snapshot: BatterySnapshot, session s: inout Session) {
        if settings.paused {
            s.dischargeTarget = nil
            s.toppingUp = false
            s.autoSuppressed = false
            s.weakSamples = 0
            return
        }
        if s.dischargeTarget == nil && !snapshot.adapterConnected {
            s.toppingUp = false
            s.autoSuppressed = false
        }
        if let target = s.dischargeTarget, snapshot.percent <= target {
            s.dischargeTarget = nil
        }
        if snapshot.percent <= settings.chargeLimit {
            s.autoSuppressed = false
        }
        if s.dischargeTarget == nil, s.canStartDischarge, !s.toppingUp, !s.autoSuppressed,
           settings.autoDischarge, snapshot.adapterConnected, snapshot.percent > settings.chargeLimit {
            s.dischargeTarget = settings.chargeLimit
        }
        let weak = s.dischargeTarget == nil && snapshot.adapterConnected && snapshot.batteryWatts < 0
        s.weakSamples = weak ? s.weakSamples + 1 : 0
    }

    /// Derives the desired hardware state; no side effects.
    static func actuation(settings: Settings, snapshot: BatterySnapshot, session s: Session) -> Actuation {
        if settings.paused { return .released }
        let discharging = s.dischargeTarget != nil
        let limit: Int? = (s.toppingUp || settings.chargeLimit >= 100) ? nil : settings.chargeLimit
        return Actuation(chargeLimit: limit,
                         adapterEnabled: !discharging,
                         led: led(settings.ledMode, snapshot, discharging: discharging),
                         preventSleep: discharging)
    }

    private static func led(_ mode: LEDMode, _ snapshot: BatterySnapshot, discharging: Bool) -> LEDState {
        if discharging { return mode == .blink ? .blinkSlow : .off }
        if !snapshot.adapterConnected { return .system }
        if mode == .off { return .off }
        return snapshot.isCharging ? .orange : .green
    }
}
```

```swift
public enum Event: Equatable, Sendable {
    /// Daemon launch: re-enables the adapter before anything else, then re-applies all state.
    case start
    case tick
    case powerChanged
    /// Must be handled before acknowledging sleep; returns with the adapter enabled.
    case willSleep
    case didWake
    case lid(closed: Bool)
    case command(Request)
}

/// Owns every charging rule. Feed it events; it writes only what changed through `Hardware`.
/// Not thread-safe: call from one serial context.
public final class Engine {
    public private(set) var settings: Settings
    private let hardware: any Hardware
    private var session = Session()
    /// Last actuation written; nil means unknown, so everything is written.
    private var applied: Actuation?
    private var snapshot: BatterySnapshot?

    public init(hardware: any Hardware, settings: Settings) {
        self.hardware = hardware
        self.settings = settings
    }

    @discardableResult
    public func handle(_ event: Event) -> Status {
        switch event {
        case .start:
            session = Session()
            applied = nil
            write(.discharge) { try hardware.setAdapter(enabled: true) }
        case .tick, .powerChanged:
            break
        case .willSleep:
            session.sleeping = true
            session.dischargeTarget = nil
        case .didWake:
            session.sleeping = false
        case .lid(let closed):
            session.lidClosed = closed
            if closed { session.dischargeTarget = nil }
        case .command(let request):
            perform(request)
        }
        evaluate()
        return status()
    }

    private func perform(_ request: Request) {
        switch request {
        case .getStatus:
            break
        case .setLimit(let limit):
            if Settings.allowedLimits.contains(limit) { settings.chargeLimit = limit }
        case .discharge(let target):
            guard (5...100).contains(target), session.canStartDischarge, !settings.paused else { return }
            session.toppingUp = false
            session.autoSuppressed = false
            session.dischargeTarget = target
        case .cancelDischarge:
            session.dischargeTarget = nil
            session.autoSuppressed = true
        case .topUp:
            guard !settings.paused else { return }
            session.toppingUp = true
            session.dischargeTarget = nil
        case .cancelTopUp:
            session.toppingUp = false
        case .setLEDMode(let mode):
            settings.ledMode = mode
        case .setAutoDischarge(let on):
            settings.autoDischarge = on
        case .setPaused(let paused):
            settings.paused = paused
        case .release:
            settings.paused = true
        }
    }

    private func evaluate() {
        do {
            snapshot = try hardware.snapshot()
        } catch {
            // Can't see the battery: stop any Discharge, keep everything else as is.
            snapshot = nil
            session.dischargeTarget = nil
            if var safe = applied {
                safe.adapterEnabled = true
                safe.preventSleep = false
                apply(safe, snapshot: nil)
            } else {
                write(.discharge) { try hardware.setAdapter(enabled: true) }
            }
            return
        }
        let current = snapshot!
        Policy.update(settings: settings, snapshot: current, session: &session)
        apply(Policy.actuation(settings: settings, snapshot: current, session: session), snapshot: current)
    }

    private func apply(_ desired: Actuation, snapshot: BatterySnapshot?) {
        var next = desired
        if changed(\.adapterEnabled, to: next) {
            write(.discharge) { try hardware.setAdapter(enabled: next.adapterEnabled) }
            // Cutting the adapter failed: the Discharge was dropped, so derive the rest again.
            if !next.adapterEnabled, session.dischargeTarget == nil, let snapshot {
                next = Policy.actuation(settings: settings, snapshot: snapshot, session: session)
            }
        }
        if changed(\.chargeLimit, to: next) { write(.chargeLimit) { try hardware.setChargeLimit(next.chargeLimit) } }
        if changed(\.led, to: next) { write(.led) { try hardware.setLED(next.led) } }
        if changed(\.preventSleep, to: next) { hardware.setPreventSleep(next.preventSleep) }
        applied = next
    }

    private func changed<T: Equatable>(_ field: KeyPath<Actuation, T>, to next: Actuation) -> Bool {
        applied.map { $0[keyPath: field] != next[keyPath: field] } ?? true
    }

    /// Runs a hardware write unless the feature is already unavailable; a failure makes it unavailable.
    private func write(_ feature: Feature, _ operation: () throws -> Void) {
        guard !session.unavailable.contains(feature) else { return }
        do {
            try operation()
        } catch {
            session.unavailable.insert(feature)
            if feature == .discharge { session.dischargeTarget = nil }
        }
    }

    private func status() -> Status {
        var warnings: [Warning] = []
        if session.weakSamples >= 2 { warnings.append(.weakAdapter) }
        warnings += Feature.allCases.filter(session.unavailable.contains).map(Warning.unavailable)
        if snapshot == nil { warnings.append(.batteryUnreadable) }
        return Status(state: state(), settings: settings, snapshot: snapshot,
                      dischargeTarget: session.dischargeTarget, warnings: warnings)
    }

    private func state() -> ChargeState {
        if settings.paused { return .paused }
        guard let snapshot else { return .unknown }
        if session.dischargeTarget != nil { return .discharging }
        if session.toppingUp { return .toppingUp }
        if !snapshot.adapterConnected { return .onBattery }
        return snapshot.isCharging ? .charging : .atLimit
    }
}
```

```c
#include "CPlatform.h"
#include <string.h>

typedef struct { uint8_t major, minor, build, reserved; uint16_t release; } SMCVersion;
typedef struct { uint16_t version, length; uint32_t cpuPLimit, gpuPLimit, memPLimit; } SMCPLimit;
typedef struct { uint32_t dataSize; uint32_t dataType; uint8_t dataAttributes; } SMCKeyInfo;
typedef struct {
    uint32_t key;
    SMCVersion vers;
    SMCPLimit pLimit;
    SMCKeyInfo keyInfo;
    uint8_t result, status, data8;
    uint32_t data32;
    uint8_t bytes[32];
} SMCParam;   // 80 bytes

enum { kSMCUserClientSelector = 2, kSMCReadKey = 5, kSMCWriteKey = 6, kSMCGetKeyInfo = 9 };

static uint32_t fourcc(const char *k) {
    return ((uint32_t)k[0] << 24) | ((uint32_t)k[1] << 16) | ((uint32_t)k[2] << 8) | (uint32_t)k[3];
}

static kern_return_t call(io_connect_t c, SMCParam *in, SMCParam *out) {
    size_t outSize = sizeof(*out);
    return IOConnectCallStructMethod(c, kSMCUserClientSelector, in, sizeof(*in), out, &outSize);
}

static kern_return_t key_info(io_connect_t c, const char *key, SMCKeyInfo *info, uint8_t *smc_result) {
    SMCParam in = {0}, out = {0};
    in.key = fourcc(key);
    in.data8 = kSMCGetKeyInfo;
    kern_return_t kr = call(c, &in, &out);
    *smc_result = out.result;
    *info = out.keyInfo;
    return kr;
}

kern_return_t smc_open(io_connect_t *out) {
    io_service_t svc = IOServiceGetMatchingService(kIOMainPortDefault, IOServiceMatching("AppleSMC"));
    if (!svc) return kIOReturnNotFound;
    kern_return_t kr = IOServiceOpen(svc, mach_task_self(), 0, out);
    IOObjectRelease(svc);
    return kr;
}

void smc_close(io_connect_t conn) { IOServiceClose(conn); }

kern_return_t smc_read(io_connect_t c, const char *key, uint8_t *buf, uint32_t *size, uint8_t *smc_result) {
    if (strlen(key) != 4) return kIOReturnBadArgument;
    SMCKeyInfo info;
    kern_return_t kr = key_info(c, key, &info, smc_result);
    if (kr != KERN_SUCCESS || *smc_result != 0) return kr;
    if (info.dataSize > 32) return kIOReturnBadArgument;
    SMCParam in = {0}, out = {0};
    in.key = fourcc(key);
    in.keyInfo.dataSize = info.dataSize;
    in.data8 = kSMCReadKey;
    kr = call(c, &in, &out);
    *smc_result = out.result;
    if (kr != KERN_SUCCESS || out.result != 0) return kr;
    memcpy(buf, out.bytes, info.dataSize);
    *size = info.dataSize;
    return KERN_SUCCESS;
}

kern_return_t smc_write(io_connect_t c, const char *key, const uint8_t *buf, uint32_t size, uint8_t *smc_result) {
    if (strlen(key) != 4 || size > 32) return kIOReturnBadArgument;
    SMCKeyInfo info;
    kern_return_t kr = key_info(c, key, &info, smc_result);
    if (kr != KERN_SUCCESS || *smc_result != 0) return kr;
    if (info.dataSize != size) return kIOReturnBadArgument;
    SMCParam in = {0}, out = {0};
    in.key = fourcc(key);
    in.keyInfo.dataSize = size;
    in.data8 = kSMCWriteKey;
    memcpy(in.bytes, buf, size);
    kr = call(c, &in, &out);
    *smc_result = out.result;
    return kr;
}
```

```swift
import Foundation
import IOKit
import IOKit.pwr_mgt
import CPlatform
import EnerGCore

/// The real Mac: AppleSMC (CHIE adapter cut, ACLC LED, PSTR system power), PowerUI native
/// Charge Limit, and the AppleSmartBattery registry entry. Writes need root.
/// SMC reads straight after a write can return the old value; the Engine never reads back, so this is harmless.
public final class MacHardware: Hardware {
    private let smc: io_connect_t
    private var sleepAssertion: IOPMAssertionID = 0

    public init() throws {
        var conn: io_connect_t = 0
        let kr = smc_open(&conn)
        guard kr == KERN_SUCCESS else { throw HardwareError.io(kr) }
        smc = conn
    }

    deinit {
        if sleepAssertion != 0 { IOPMAssertionRelease(sleepAssertion) }
        smc_close(smc)
    }

    public func snapshot() throws -> BatterySnapshot {
        let p = try Self.batteryProperties()
        func number(_ key: String) -> NSNumber? { p[key] as? NSNumber }
        let milliamps = Double(number("InstantAmperage")?.int64Value ?? 0)
        let millivolts = Double(number("Voltage")?.int64Value ?? 0)
        let adapter = p["AdapterDetails"] as? [String: Any]
        return BatterySnapshot(
            percent: number("CurrentCapacity")?.intValue ?? 0,
            isCharging: p["IsCharging"] as? Bool ?? false,
            adapterConnected: p["ExternalConnected"] as? Bool ?? false,
            adapterWatts: (adapter?["Watts"] as? NSNumber)?.intValue,
            batteryWatts: milliamps * millivolts / 1_000_000,
            systemWatts: (try? readFloat("PSTR")).map(Double.init)
        )
    }

    public func setChargeLimit(_ percent: Int?) throws {
        if let percent {
            try check(powerui_set_limit(UInt8(percent)))
            try check(powerui_set_enabled(true))
        } else {
            try check(powerui_set_enabled(false))
        }
    }

    public func setAdapter(enabled: Bool) throws {
        try write("CHIE", enabled ? 0x00 : 0x08)
    }

    public func setLED(_ state: LEDState) throws {
        let value: UInt8 = switch state {
        case .system: 0x00
        case .off: 0x01
        case .green: 0x03
        case .orange: 0x04
        case .blinkSlow: 0x06
        }
        try write("ACLC", value)
    }

    public func setPreventSleep(_ on: Bool) {
        if on, sleepAssertion == 0 {
            IOPMAssertionCreateWithName("PreventUserIdleSystemSleep" as CFString,
                                        IOPMAssertionLevel(kIOPMAssertionLevelOn),
                                        "EnerG Discharge" as CFString, &sleepAssertion)
        } else if !on, sleepAssertion != 0 {
            IOPMAssertionRelease(sleepAssertion)
            sleepAssertion = 0
        }
    }

    // MARK: - SMC

    private static let notPrivileged = kern_return_t(bitPattern: 0xE000_02C1)
    private static let keyNotFound: UInt8 = 132

    private func write(_ key: String, _ byte: UInt8) throws {
        var result: UInt8 = 0
        var value = byte
        let kr = smc_write(smc, key, &value, 1, &result)
        try checkSMC(kr, result, key)
    }

    private func readFloat(_ key: String) throws -> Float {
        var buf = [UInt8](repeating: 0, count: 32)
        var size: UInt32 = 0
        var result: UInt8 = 0
        let kr = smc_read(smc, key, &buf, &size, &result)
        try checkSMC(kr, result, key)
        guard size == 4 else { throw HardwareError.keyMissing(key) }
        let bits = UInt32(buf[0]) | UInt32(buf[1]) << 8 | UInt32(buf[2]) << 16 | UInt32(buf[3]) << 24
        return Float(bitPattern: bits)
    }

    private func checkSMC(_ kr: kern_return_t, _ result: UInt8, _ key: String) throws {
        if kr == Self.notPrivileged { throw HardwareError.notPrivileged }
        guard kr == KERN_SUCCESS else { throw HardwareError.io(kr) }
        if result == Self.keyNotFound { throw HardwareError.keyMissing(key) }
        guard result == 0 else { throw HardwareError.io(Int32(result)) }
    }

    private func check(_ rc: Int32) throws {
        switch rc {
        case 0: return
        case -1: throw HardwareError.frameworkUnavailable
        default: throw HardwareError.io(rc)
        }
    }

    // MARK: - Battery registry

    private static func batteryProperties() throws -> [String: Any] {
        let service = IOServiceGetMatchingService(kIOMainPortDefault, IOServiceMatching("AppleSmartBattery"))
        guard service != 0 else { throw HardwareError.keyMissing("AppleSmartBattery") }
        defer { IOObjectRelease(service) }
        var props: Unmanaged<CFMutableDictionary>?
        let kr = IORegistryEntryCreateCFProperties(service, &props, kCFAllocatorDefault, 0)
        guard kr == KERN_SUCCESS, let dict = props?.takeRetainedValue() as? [String: Any] else {
            throw HardwareError.io(kr)
        }
        return dict
    }
}
```

```swift
/// different threads) and persists settings whenever a call changed them.
final class EngineHost: @unchecked Sendable {

    private let log = Logger(subsystem: "app.energ", category: "energd")

    @discardableResult

                do { try store.save(engine.settings) } catch {
                    log.error("saving settings failed: \(String(describing: error), privacy: .public)")
                }
            }
            return status
        }
```

```swift
import Foundation
import IOKit
import IOKit.ps
import IOKit.pwr_mgt

// IOKit message constants are function-like macros that Swift does not import.
private let messageCanSystemSleep: natural_t = 0xE000_0270
private let messageSystemWillSleep: natural_t = 0xE000_0280
private let messageSystemHasPoweredOn: natural_t = 0xE000_0300
private let messageClamshellStateChange: natural_t = 0xE003_4100

/// Feeds power-source, sleep/wake, lid and timer events into the EngineHost.
/// Call `start()` on the main thread; callbacks arrive on the main run loop.
final class SystemEvents {
    private let host: EngineHost
    private var rootPort: io_connect_t = 0
    private var notifyPort: IONotificationPortRef?
    private var sleepNotifier: io_object_t = 0
    private var lidNotifier: io_object_t = 0
    private var timer: Timer?

    init(host: EngineHost) { self.host = host }

    func start() {
        let context = Unmanaged.passUnretained(self).toOpaque()

        // Plug, unplug and percentage changes.
        if let source = IOPSNotificationCreateRunLoopSource({ context in
            Unmanaged<SystemEvents>.fromOpaque(context!).takeUnretainedValue().host.handle(.powerChanged)
        }, context)?.takeRetainedValue() {
            CFRunLoopAddSource(CFRunLoopGetMain(), source, .defaultMode)
        }

        // Sleep and wake.
        rootPort = IORegisterForSystemPower(context, &notifyPort, { context, _, type, argument in
            Unmanaged<SystemEvents>.fromOpaque(context!).takeUnretainedValue().power(type, argument)
        }, &sleepNotifier)
        guard let notifyPort else { return }
        CFRunLoopAddSource(CFRunLoopGetMain(), IONotificationPortGetRunLoopSource(notifyPort).takeUnretainedValue(), .defaultMode)

        // Lid (clamshell) changes, plus the current state.
        let rootDomain = IOServiceGetMatchingService(kIOMainPortDefault, IOServiceMatching("IOPMrootDomain"))
        IOServiceAddInterestNotification(notifyPort, rootDomain, kIOGeneralInterest, { context, _, type, argument in
            guard type == messageClamshellStateChange else { return }
            let closed = (UInt(bitPattern: argument) & 1) != 0
            Unmanaged<SystemEvents>.fromOpaque(context!).takeUnretainedValue().host.handle(.lid(closed: closed))
        }, context, &lidNotifier)
        let closed = IORegistryEntryCreateCFProperty(rootDomain, "AppleClamshellState" as CFString, kCFAllocatorDefault, 0)?
            .takeRetainedValue() as? Bool ?? false
        IOObjectRelease(rootDomain)
        host.handle(.lid(closed: closed))

        timer = Timer.scheduledTimer(withTimeInterval: 30, repeats: true) { [host] _ in host.handle(.tick) }
    }

    private func power(_ type: natural_t, _ argument: UnsafeMutableRawPointer?) {
        switch type {
        case messageCanSystemSleep:
            IOAllowPowerChange(rootPort, Int(bitPattern: argument))
        case messageSystemWillSleep:
            host.handle(.willSleep)   // re-enables the adapter synchronously
            IOAllowPowerChange(rootPort, Int(bitPattern: argument))
        case messageSystemHasPoweredOn:
            host.handle(.didWake)
        default:
            break
        }
    }
}
```

```swift
import XPC
import EnerGCore

/// Sends one Request to energd. A fresh session per call: calls are rare
/// (2 s polling while the popover is open), and this avoids stale-session handling.
struct DaemonClient: Sendable {
    func send(_ request: Request) async throws -> Status {
        try await withCheckedThrowingContinuation { continuation in
            do {
                let session = try XPCSession(machService: DaemonID.machService, options: .privileged,
                                             requirement: .isFromSameTeam())
                try session.send(request) { (result: Result<Status, any Error>) in
                    session.cancel(reason: "done")
                    continuation.resume(with: result)
                }
            } catch {
                continuation.resume(throwing: error)
            }
        }
    }
}
```

```swift
import AppKit
import Observation
import ServiceManagement
import EnerGCore

@MainActor @Observable
final class AppModel {
    var status: Status?
    var helper: SMAppService.Status = HelperInstaller.status
    var errorText: String?
    var alDenteRunning = false
    var launchAtLogin = HelperInstaller.launchAtLogin
    /// Discharge Target chosen in the Discharge popover; defaults to the Charge Limit on first status.
    var dischargeTarget = 80

    private let client = DaemonClient()
    private var polling: Task<Void, Never>?

    init() {
        // Launch at login defaults to on, once.
        let key = "launchAtLoginInitialized"
        if !UserDefaults.standard.bool(forKey: key) {
            try? HelperInstaller.setLaunchAtLogin(true)
            UserDefaults.standard.set(true, forKey: key)
            launchAtLogin = HelperInstaller.launchAtLogin
        }
    }

    func startPolling() {
        polling?.cancel()
        polling = Task {
            while !Task.isCancelled {
                await refresh()
                try? await Task.sleep(for: .seconds(2))
            }
        }
    }

    func stopPolling() {
        polling?.cancel()
        polling = nil
    }

    func refresh() async {
        helper = HelperInstaller.status
        alDenteRunning = NSWorkspace.shared.runningApplications
            .contains { $0.bundleIdentifier == "com.apphousekitchen.aldente-pro" }
        guard helper == .enabled else {
            status = nil
            return
        }
        await send(.getStatus)
    }

    func send(_ request: Request) async {
        do {
            let new = try await client.send(request)
            if status == nil { dischargeTarget = new.settings.chargeLimit }
            status = new
            errorText = nil
        } catch {
            errorText = "Helper not reachable: \(error.localizedDescription)"
        }
    }

    func installHelper() {
        do { try HelperInstaller.register() } catch { errorText = "Install failed: \(error.localizedDescription)" }
        helper = HelperInstaller.status
        if helper == .requiresApproval { HelperInstaller.openApproval() }
    }

    func uninstallHelper() async {
        await send(.release)
        do { try await HelperInstaller.unregister() } catch { errorText = "Uninstall failed: \(error.localizedDescription)" }
        helper = HelperInstaller.status
        status = nil
    }

    func setLaunchAtLogin(_ on: Bool) {
        do { try HelperInstaller.setLaunchAtLogin(on) } catch { errorText = error.localizedDescription }
        launchAtLogin = HelperInstaller.launchAtLogin
    }
}
```

````markdown
# EnerG

Menu bar app that keeps a MacBook below a Charge Limit and runs it from the adapter instead of cycling the battery. Open-source alternative to the parts of AlDente its author uses: Charge Limit, Discharge / Auto-Discharge, MagSafe LED control, Top Up and Pause. Terms are defined in [CONTEXT.md](CONTEXT.md).

**Requirements:** an Apple Silicon MacBook on macOS 27, with firmware that gates the SMC charge-inhibit keys (macOS 27, or the 26.7 / 15.8 security updates). Intel Macs are not supported.

## How it works

- **Charge Limit** uses the native macOS limit (80/85/90/95/100%) through the private PowerUI framework.
- **Discharge** cuts adapter power with the SMC key `CHIE`.
- **MagSafe LED** is driven through the SMC key `ACLC`.
- A root helper (`energd`, registered with `SMAppService`) does the writes. The menu bar app talks to it over XPC. Only apps signed by the same team can connect.
````
